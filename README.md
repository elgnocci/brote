# Brote

App Android para fumar menos, con una mascota (un brote en su islita) que se enferma si te pasas del límite del día y se recupera si cumples.

## Instalar la versión de prueba

1. Pestaña **Actions** → la última ejecución en verde de **build**.
2. Descarga el artefacto **app-debug** (es un .zip con el APK adentro).
3. Instala `app-debug.apk` en el teléfono (Android pide permitir "instalar apps desconocidas").
